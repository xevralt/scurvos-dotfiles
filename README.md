# scurvos-dotfiles

My Arch Linux dotfiles for a Tokyo Night / Cyberpunk Hyprland setup.

## Components

- Hyprland — Wayland compositor
- Waybar — status bar
- Rofi — application launcher
- Kitty — terminal

## Theme

Tokyo Night with electric purple and cyan accents.

## Structure

- `hypr/` — Hyprland configuration
- `waybar/` — Waybar configuration and styling
- `rofi/themes/` — Rofi themes
- `kitty/` — Kitty terminal configuration
